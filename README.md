# 博物声 · 博物馆展陈脚本工作台

面向博物馆内容团队的展陈脚本编写、审校与版本管理工具。项目按“展厅 → 展项 → 语言”组织内容，覆盖标题、讲解词、无障碍描述、朗读时长和资料来源。

## 功能

- 展厅、展项切换，以及中文、英文、日文多语言稿件进度对照。
- 草稿、待审、退回、已定稿四态流转；已确认段落可锁定，避免误改。
- 分段校对、预计朗读时长、自动字数/语速估算和来源核验。
- 完整版本快照、句子级差异比较和版本恢复。
- 术语审校：登记中文词与英日标准译法（旧译法保留），按段落列出漏译、旧译、同段混用；可定位并预览替换，已确认段落只提示不写入，放弃检查不改正文；版本快照冻结检查结果，恢复时一并回到当时。
- 桌面、平板、手机、馆内触摸屏四种排版预览。
- 浏览器本地持久化，刷新后恢复；最多 50 步撤销重做。
- `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`、`Ctrl/⌘ + S` 快捷键与语义化表单标签。

## 术语审校说明

- 术语、检查结果与审校记录（术语、段落、时间）均保存在浏览器 `localStorage`（键 `museum-script-studio-v2`），重开后可继续处理；旧 v1 数据会自动迁移。
- 调整某条术语的标准译法时，原标准译法会自动并入“旧译法”，历史译法不会丢失。
- 打开展项的英文/日文文稿时自动检查；漏译（外文中残留中文词）只给建议译法，需人工补译，不会自动写入。
- 引擎逻辑与 store 全流程附有冒烟测试（`scripts/`，经 esbuild 转译后可直接用 node 运行）。

## 技术栈

- Nuxt 3、Vue 3、TypeScript、Pinia
- Vuetify 3
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:3000`。应用不包含宿主端口配置。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `.output/public`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1004 .
docker run --rm -p 10004:80 sologsb-1004
```

容器内 nginx 监听 80，静态单页回退到 `index.html`。根据根端口表，本地映射为宿主 `10004`。

## 数据说明

所有数据只保存在当前浏览器。清除站点数据会删除本地稿件；版本快照保存在同一份本地数据中。
